# Data

The analysis uses the historical workbook [nordic_gdp_health_panel_2000_2018.xlsx](raw/nordic_gdp_health_panel_2000_2018.xlsx). It contains 76 annual observations for Denmark, Finland, Norway, and Sweden from 2000 through 2018. The panel has 19 observations per country.

Stata imports cells A2:H77 from `Sheet1`. The level variables in these columns are used to construct the logarithms in the do-file. Formula-generated logarithms elsewhere in the workbook are not imported.

| Excel column | Stata variable | Meaning |
| --- | --- | --- |
| A | `country_name` | Country name |
| B | `year` | Calendar year |
| C | `country_id` | Country identifier |
| D | `time_id` | Year index within country |
| E | `gdp` | Gross domestic product |
| F | `life_expectancy` | Life expectancy at birth |
| G | `age_dependency` | Age-dependency ratio |
| H | `population` | Population field in the historical workbook |

The do-file calculates natural logarithms of GDP (`lngdp`), life expectancy (`lnl`), the age-dependency ratio (`lna`), and the population field (`lnp`). The processed Stata dataset in [processed/](processed/nordic_gdp_health_panel_2000_2018.dta) is a derived file and can be regenerated by running the analysis.

## Source documentation and units

The workbook does not contain source URLs, indicator codes, retrieval dates, or a complete data dictionary. The price basis and units of GDP cannot be independently established from the workbook and the series are used as recorded.

Denmark's population field ranges from approximately 69,650 to 71,625, whereas the corresponding values for Finland, Norway, and Sweden are in the millions. The source workbook does not explain whether this reflects a unit difference or a variable-definition difference. The historical values are retained without adjustment; estimates involving population should be interpreted cautiously.

## Input integrity

The SHA-256 digest of the committed workbook is recorded in [raw.sha256](raw.sha256). The repository's GitHub Actions workflow checks this digest so that an unintended change to the input file is detected.
