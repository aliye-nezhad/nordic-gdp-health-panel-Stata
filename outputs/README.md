# Output files

The files currently committed under this directory are reference outputs from an earlier Stata execution. They are retained to show the form of the descriptive statistics, correlation matrix, specification tests, model comparison, and country-level figures.

They are not generated by GitHub Actions, and the current workflow does not execute Stata. To generate a fresh set of outputs from the current do-file, run `do replication/run_analysis.do` in Stata 15.1 or later from the repository root. The script replaces files at its output paths in the working copy.

## Committed reference files

### Tables

- `tables/descriptive_statistics.txt`: descriptive statistics for the logged variables.
- `tables/correlation_matrix.txt`: pairwise correlations among the logged variables.
- `tables/hausman_test.txt`: Hausman comparison of fixed-effects and random-effects estimates.
- `tables/model_comparison.txt`: FE, RE, FE-AR(1), and FGLS-AR(1) estimates.

### Figures

- `figures/log_gdp_by_country.png`: log GDP over time.
- `figures/life_expectancy_by_country.png`: life expectancy over time.
- `figures/age_dependency_by_country.png`: age-dependency ratio over time.

## Additional files generated by a new run

The current do-file also creates the Wooldridge/Drukker diagnostic report, a fixed-effects residuals-versus-fitted figure, the processed Stata dataset, and the main execution log. These files are listed in the [reproducibility guide](../docs/REPRODUCIBILITY.md).

The committed files should be treated as reference snapshots, not as evidence that the current version of the do-file has been executed in the GitHub Actions environment. A fresh Stata run is required to verify the current numerical results.
